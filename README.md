A single honest-but-funny household-appliance error message for the make.fun competition **The Funniest Honest Appliance Error**.

`main.py` writes one line of text (107 characters) to `/output/entry.txt`:

> Error 0xTOAST: the toaster burned your bread, blamed the bread, and has filed a warranty claim against you.

Run it with `python3 main.py` (writes to `$MAKEFUN_OUTPUT_DIR`, default `/output`).
